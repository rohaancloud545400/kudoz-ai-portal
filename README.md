# 🛡️ Kudoz AI v3: Student & Parent Monitoring Portal
> **Zero-Maintenance Public Static Dashboard Powered by GitHub Pages**

This repository is the public static frontend for **Kudoz AI v3**. It contains no private data analysis scripts, background scrapers, or raw activity logs. It is automatically updated by the private `kudoz-ai` backend whenever fresh daily summaries or weekly reward certificates are generated.

---

## 🌐 Live Access

Open the portal directly in any browser (no local setup or Python required):
👉 **`https://<YOUR-GITHUB-USERNAME>.github.io/kudoz-ai-portal/`**

---

## 📱 Portal Tabs & User Views

| Tab | Target Audience | Features & Available Content |
|:---|:---|:---|
| **🎮 Student Portal** | Student | View and download today's `Summary_For_Kids` quest along with trailing 7 days of daily screen-time progress and level-up badges. |
| **👨‍👩‍👦 Parent Portal** | Parents & Mentors | View and download today's and trailing 7 days of `Productivity_Report` executive summaries, application usage tables, and distraction anomaly tracking. |
| **🏆 Weekly Certificates** | Student & Family | View and print the official multi-pillar `Weekly_Reward_Report_V2` audits and unlocked gold-bordered Saturday Reward Certificates. |
| **⚙️ Administrator Logs** | System Admin | Live 7-day health audit matrix verifying daily PDF compilation and feedback JSON submissions. |

---

## 🔄 Automated Delivery Schedule

* **Daily Dual Reports**: Refreshed every night at **10:40 PM PKT (17:40 UTC)**.
* **Weekly Reward Certificates**: Published every Saturday at **10:40 AM PKT (05:40 UTC)**.

---

## 🔒 Security & Privacy Notice
* **Metadata Only**: All displayed daily reports track window titles and applications only; no keystrokes, webcam footage, or screen recordings are ever captured.
* **Static Deployment**: This frontend hosts only pre-rendered HTML and finalized PDF deliverables. All proprietary prompts, machine learning workflows, and raw input files remain isolated inside the private repository.
